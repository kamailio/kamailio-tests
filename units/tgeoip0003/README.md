# Geoip2 Module - Database Reload #

Summary: geoip2 module - geoip2.reload with replaced, missing and corrupt database files

Uses a database generated by `libs/mkmmdb.py`. Its `reload` variant has
different data for `192.0.2.0/24` (Cluj-Napoca instead of Bucharest), so
the unit can tell which file a worker uses. Several requests are sent per
step so that all SIP workers are checked.

Following tests are done:

  * initial lookups use the database from startup
  * replacing the file (move, not overwrite) changes nothing until
    `geoip2.reload` is run
  * after `geoip2.reload` all workers use the new data
  * `geoip2.reload` with an unchanged file keeps working
  * missing file and a file with random bytes: lookups fail, kamailio
    keeps running
  * after the valid file is back and reloaded, lookups work again

Requires `python3` and `sipsak`.
